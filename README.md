# 霓虹禁区：最后防线 / NEON OUTBREAK

一款纯前端、零依赖的 2D 俯视角 Roguelite 生存射击游戏。标准任务单局 **6 分钟**：在不断涌出的机械军团中活下来，并在 03:00 与 06:00 迎战两名核心首领。另有无尽模式——越久越强，首领无限循环刷新。

公元 2189 年，NEON-07 的未来都市遭遇失控人工智能入侵。你是被困在城市核心区的战斗人员，装备实验型能源武器。目标是坚持六分钟、摧毁最终防御核心、成功撤离。

## 一、启动方式

项目是**纯静态网页**，没有构建步骤、没有外部 CDN、没有后端。

### 方式 A：本地 HTTP 服务器（推荐）

```bash
cd neon-outbreak
python -m http.server 8791 --bind 127.0.0.1
```

然后在浏览器打开：

```
http://127.0.0.1:8791/
```

也可以使用 `npx serve .` 或任何静态服务器。

### 方式 B：直接双击 index.html

项目使用传统 `<script defer>` 而不是 ES Modules，因此**直接双击 `index.html` 用 `file://` 打开也能正常运行**。但部分浏览器对 `file://` 下的 `localStorage` 限制更严格，历史纪录可能无法保存。想要完整的存档体验，请使用方式 A。

### 自动化测试入口

在 URL 后加 `?test=1` 会注入测试钩子（正常游玩不会加载，也不会暴露作弊入口）：

```
http://127.0.0.1:8791/index.html?test=1
```

### 两个版本号，别混淆

| 名称 | 例子 | 含义 |
| --- | --- | --- |
| 功能版本 | `1.2.0` | 菜单右上角显示的版本，玩家能看到的“第几版游戏”，改功能时手动递增 |
| 构建号 | `v23` | 只出现在 `index.html` 的 `?v=23` 里，**纯粹是防缓存用的计数**，每改一次代码 +1 |

`?v=N` 不改变文件内容，浏览器请求的还是 `js/utils.js`。它唯一的作用是让 URL 变化，从而绕过浏览器本地缓存。改过 JS/CSS 之后不递增它，就会出现“代码改了但页面没变”的假象——这轮开发真的踩过一次（`style.css` 链接漏了版本串，HUD 新增的计量条样式整块没生效）。

打开控制台后可以运行 `tests/soak.js` 里的机器人，做全流程回归：

```js
// 在控制台执行
fetch('/tests/soak.js?cb=' + Date.now(), { cache: 'no-store' })
  .then(r => r.text()).then(t => eval(t));
window.__soak(1500);   // 模拟到结束，返回胜负、击杀、升级、伤害归因
```

## 二、操作方式

### 桌面端

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动（支持斜向，速度已归一化） |
| `Enter` | 冲刺（0.18 秒无敌 + 落地 0.14 秒护盾，冷却 3 秒） |
| `Esc` | 暂停 / 继续 / 关闭设置 |
| `M` | 静音切换 |
| `1` `2` `3` | 升级时快速选择对应卡片 |
| `Enter` | 菜单开始 / 结算重开 / 跳过 BOSS 演出 |

射击是**自动**的：武器始终锁定射程内最近的敌人（BOSS 战时优先清掉贴身杂兵），你只需要专注走位。

### 冲刺无敌帧（相位闪避）

冲刺不只是位移，它是这个游戏的核心防守手段：

- 冲刺的 **0.18 秒**全程无敌，结束后还会保留 **0.14 秒**落地护盾，避免「刚落地就被子弹收掉」。
- 无敌期间穿过敌方子弹，子弹会被**相位消解**并炸出绿色火花——这是主动收益，不是白跑。
- 每次成功消解都会累计「完美闪避」次数，累计到一定数量会弹出 `PHASE` 提示。
- 只有冲刺相位会吞子弹；普通受击后的 0.6 秒无敌不会，避免站着不动也能清弹幕。

### 移动端

- 左下角虚拟摇杆：移动
- 右下角冲刺进度条：整条就是按钮，点按即可冲刺；条满即就绪
- 右上角暂停按钮
- 点击「开始任务」时会（在浏览器允许的前提下）请求全屏并尝试锁定横屏
- 升级卡片、设置、按钮全部支持触摸
- 竖屏时会显示横屏建议，横屏体验最佳

## 三、玩法系统

### 成长

击杀敌人掉落经验晶体，靠近自动吸附。经验满格后进入**三选一强化**，游戏会暂停直到你做出选择。单局通常能升到 **12～20 级**。

**22 种强化模块**，分五档稀有度（常规 / 精良 / 稀有 / 史诗 / 传说），每种都有等级上限，满级后不再出现在候选池里。升级卡片会直接显示**这一级会把数值从多少改到多少**（`220 ▸ 246`、`3.00s ▸ 2.40s`），不用自己算。

| 模块 | 稀有度 | 效果 | 上限 |
| --- | --- | --- | --- |
| 火力强化 | 常规 | 武器伤害 +20% | 5 |
| 极速射击 | 常规 | 攻击间隔 -12% | 5 |
| 能量护甲 | 常规 | 最大生命值 +25（并立即治疗等量） | 4 |
| 自我修复 | 常规 | 立即恢复 30 点生命 | 5 |
| 机动强化 | 常规 | 移动速度 +12% | 4 |
| 弹道穿透 | 精良 | 子弹穿透 +1 | 3 |
| 暴击模块 | 精良 | 暴击率 +8 个百分点 | 4 |
| 磁力核心 | 精良 | 经验拾取范围 +40% | 3 |
| 多重射击 | 稀有 | 每轮额外发射 1 枚子弹 | 3 |
| 电磁脉冲 | 稀有 | 周期性对周围敌人造成范围伤害 | 4 |
| 冰霜核心 | 精良 | 命中时有概率造成减速 | 3 |
| 能量爆裂 | 稀有 | 击杀时概率触发范围爆炸 | 3 |
| 过载核心 | 稀有 | 暴击倍率 +0.25（1.50 → 1.75 …） | 3 |
| 能量汲取 | 稀有 | 每次击杀回复 2 点生命 | 4 |
| 反制装甲 | 精良 | 受击时把 40% 伤害反弹给攻击者 | 3 |
| 力场护盾 | 史诗 | 每 11 秒充能一层护盾，抵挡一次伤害 | 3 |
| 追踪弹道 | 稀有 | 子弹会向附近敌人转向 | 2 |
| 相位冲击 | 稀有 | 冲刺结束时释放范围冲击波 | 3 |
| 数据解析 | 精良 | 经验获取 +25% | 3 |
| 伺服过载 | 精良 | 冲刺冷却 -20%（最低 1.2 秒） | 3 |
| 处决协议 | 史诗 | 对生命低于 30% 的敌人造成额外伤害 | 2 |
| 跳弹 | 传说 | 子弹命中后弹向附近另一个目标 | 2 |

若可用强化不足三张，会用应急卡补齐：应急维修（治疗 25）、数据缓存（+400 分）、临时超频（+10% 伤害）、装甲镀层（+8 最大生命，可无限叠）。

### HUD 成长计量条

左上角除了生命值，还实时显示 5 条成长计量条，把「看不见的数值」变成能看见的进度：

| 计量条 | 含义 | 颜色 |
| --- | --- | --- |
| `DMG` | 单发伤害倍率（×1.00 起） | 橙金 |
| `RATE` | 每秒射击次数（2.2/s 起） | 青 |
| `CRIT` | 暴击概率（5% 起） | 紫 |
| `MAG` | 拾取半径数值（160 起） | 绿 |
| `EMP` | 电磁脉冲充能进度（拿到该模块后才出现） | 红 |

矮屏横屏时这 5 条会自动排成两列紧凑布局，避免遮挡战场。

### 敌人

| 敌人 | 特征 |
| --- | --- |
| 追踪无人机 | 三角机体，低血量高速度，直线追踪 |
| 重装机器人 | 方形厚重装甲，血量高、接触伤害高、被击中有装甲反馈 |
| 狙击机器人 | 紫色细长机体，保持 300 距离，开火前有瞄准提示 |
| 自爆机械虫 | 橙色锯齿机体，冲刺接近后闪烁倒计时爆炸，有危险圈提示 |
| 精英守卫 | 大型多边形装甲，会预告方向后冲锋，掉落更多经验、必掉维修包 |

难度按时间推进，分 6 个阶段，每秒生存本身也计分。

### BOSS

**机械审判者 JUDGE-09**（03:00）—— 巨型防御平台，三种攻击：环形弹幕、需预警的直线激光、冲锋。击败后播放爆炸演出、掉落大量经验、恢复 40 点生命。

**失控核心 OMEGA**（06:00）—— 最终首领，四种攻击：多方向螺旋弹幕、旋转激光、召唤机械单位、大范围能量冲击波。血量低于 50% 时进入第二阶段：外观转红、攻击频率提升、激光数量增加，并有 1.35 秒的阶段转换演出。OMEGA 登场后计时停止，但战斗继续，直到你击败它或阵亡。

### 无尽模式

主菜单可以选择「无尽模式」。规则与标准任务相同，但：

- 六分钟流程结束后**不会结算**，敌人继续以对数曲线变强（六分钟后每多一倍时间，血量增长才减半一次，避免十分钟后变成血牛）
- 首领改为**循环刷新**：每击败一次，下一只的刷新间隔缩短（62 秒起，每波 -3 秒，最低 38 秒），血量与接触伤害按波次加厚
- 第 1、3、5… 波是 JUDGE-09，第 2、4、6… 波是 OMEGA，场上永远只存在一只首领
- 每清一波恢复 25% 生命值并额外加分，右上角显示 `ENDLESS · WAVE NN`
- 结算按存活时长评级（≥14 分钟 S、≥10 分钟 A、≥7.5 分钟 B、≥6 分钟 C），并单独记录无尽最高分 / 最长时长 / 最高波次，不会污染标准任务的纪录

### 续航设计

为了让六分钟是有可能打赢的，而不是靠运气：

- **每升一级底盘自动强化**：最大生命值 +6（并同步回复等量），所以即使整局没抽到「能量护甲」，18 级时也有约 200 点生命
- 每次升级修复 12% 最大生命值（至少 10 点）
- 普通敌人有 8% 概率掉落维修包，精英必掉
- 脱战 4 秒后以 1.4 HP/秒自动修复
- 每名 BOSS 登场时自动补给 35% 生命值
- BOSS 战期间场上杂兵上限压到 24（移动端 16），刷怪间隔显著拉长
- BOSS 血量按「你当前的实测 DPS × 目标击杀时间」反推（审判者约 26 秒、OMEGA 约 30 秒），所以无论发育好坏，BOSS 战都保持在 20～26 秒的高强度区间，不会出现秒杀或打不动的极端情况

这些机制都是真实生效的数值，不是视觉演出。

│   ├── ui.js             # 全部 DOM 界面与 HUD 同步
│   ├── game.js           # 主状态机、导演、碰撞、胜负判定、渲染

├── assets/
│   └── favicon.svg
├── tests/
│   ├── smoke.js          # Playwright 冒烟测试（需本地有浏览器）

## 五、技术要点

- **游戏状态机**：`MENU / PLAYING / PAUSED / LEVEL_UP / BOSS_INTRO / GAME_OVER / VICTORY / SETTINGS`，所有切换都经过统一入口，暂停时战斗逻辑、计时、生成全部冻结。
- **主循环**：单实例 `requestAnimationFrame`，固定步长累加器（1/120 秒）配 8 步上限，`deltaTime` 上限 1/20 秒，高刷新率与低帧率都稳定；切换标签页自动暂停。
- **渲染**：`devicePixelRatio` 感知但上限 x2，Canvas 全屏铺底，HUD 用 DOM 叠在上面，避免每帧操作 DOM。
- **性能保护**：粒子上限 520、浮动文字 44、同屏敌人上限 160（移动端 92，首领战压到 24 / 16）、子弹 200、敌方子弹 260，全部用对象池式复用数组并在失效时立即剔除。
- **打击反馈**：暴击伤害数字按伤害量动态放大（普通 15px、暴击基础 34px 并随伤害继续增大），配弹出缩放与描边，重击与普攻一眼可分；所有敌人头顶常显血条（满血半透明、受损转实色），精英更粗并带紫色描边。
- **击杀音效分层**：无人机、重装机甲、自爆虫、狙击机、精英各用不同音色，并且连杀越高音高越高（detune 最多 +6 个半音），连杀 5 / 10 次额外触发上行三连音。
- **移动端横屏**：点击开始时在合法用户手势内尝试 `requestFullscreen()` + `screen.orientation.lock('landscape')`；浏览器不支持时静默降级，仍可用摇杆游玩并显示旋转提示。
- **存档**：`localStorage` 键 `neonOutbreakSave.v1`，保存最高分、最长生存时间、累计击杀、游戏次数、音量、音效开关、屏幕震动开关，以及无尽模式独立的最高分 / 最长时长 / 最高波次。存储不可用时游戏照常运行，只是不持久化。

## 六、已知限制

- `tests/smoke.js` 需要本机安装 Playwright 与 Chromium 才能运行；本次开发环境禁止派生子进程，所以该脚本未在本机执行，实际验证是通过浏览器调试接口完成的长局模拟（见交付报告）。
- 音效在用户第一次交互（点击/按键）之后才会解锁，这是浏览器自动播放策略的限制。
- `file://` 直开时部分浏览器会限制 `localStorage`，归档功能可能不可用。
